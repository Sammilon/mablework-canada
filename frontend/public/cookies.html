Cookie Directive Policy

Effective Date: May 16, 2026

Transparency details regarding tracking configurations, authorization caching, and local browser storage operations.

1. Understanding Local Storage Parameters

MableWork Canada leverages standard web storage architectures, including HTTP cookies, HTML5 local storage spaces, and localized data tokens. These components consist of small string elements saved to your device terminal by our hosting engines to retain session data states across site navigations.

2. How We Deploy Cookies

Our infrastructure deploys browser storage blocks exclusively for technical operations and system hardening. We categorize these implementations as follows:

  • Strictly Essential Functional Tracking: Used to maintain authenticated account identity instances. These files temporarily preserve encryption hashes allowing users to transit private dashboards without triggering a logout state on every page load.
  • Security Optimization Elements: Injected to verify client integrity. They protect login fields from automated brute-force scripts and form-hijacking exploits.
  • System Layout Configurations: Retain functional structural states such as collapsed sidebar navigation positions and localized preference selections.

4. Managing Local Preferences

Users maintain the absolute authority to block or flush cookie metrics through their standard web browser settings. Disabling essential cookies can prevent authorization engines from functioning correctly, which will restrict access to personal worker and employer dashboards.
